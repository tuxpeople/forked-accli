## Findings considered and rejected or deferred

- **Arbitrary JXA execution through exported `runScript`**: rejected as a security finding because a library caller already capable of calling arbitrary Node APIs has equivalent code-execution authority; CLI argv cannot select `scriptName`.
- **Config symlink/mode hardening**: rejected as a security priority because no meaningful privilege boundary exists against another same-user process. Atomic config writes may still be worthwhile as ordinary robustness work.
- **Jest-only high advisories**: deferred; `pnpm audit --prod` is clean and no reachable untrusted build/test input was demonstrated.
- **Native Swift helper migration**: rejected for now; signing, notarization, and binary distribution costs exceed the measured startup benefit at this scale.
- **TypeScript migration**: rejected for now; it does not address the dominant JXA duplication and boundary-test risks.
- **Compiled JXA caching**: rejected as a standalone optimization; measured single-invocation savings are too small and batch mode would address the structural cost better.
- **Delete UID fallback window**: deferred for investigation because UID-based deletion is not publicly documented and EventKit recurrence/identifier semantics need a design decision.
- **Declined-invitation filtering**: deferred until it can be verified against real EventKit participant-status behavior.
